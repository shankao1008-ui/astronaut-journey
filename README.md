# 太空人的太陽系之旅 · An Astronaut's Solar System Walk

**Live:** https://shankao1008-ui.github.io/astronaut-journey/

A first-person, brick-and-mosaic style walking tour of the Solar System and five exoplanets, built as a single HTML file with Three.js. Switch between 繁體中文 and English with the bar in the top-left corner.

- `index.html` — v2, first-person walking version (17 stops; moons stand in for the gas giants; observation deck for the Sun and hot Jupiters)
- `classic.html` — v1, third-person canvas animation (16 stops)

Data: NASA Solar System Exploration, NASA/JPL Horizons, NASA Exoplanet Archive, ESA Gaia. Scenes are illustrative; distances are compressed; sky objects use true angular diameters; exoplanet surfaces are inferred from size, temperature and host star.

第一人稱、積木馬賽克風格的太陽系步行之旅,單一 HTML 檔(使用 Three.js)。左上角可切換繁體中文 / English。`index.html` 為步行版,`classic.html` 為第三人稱經典版。
